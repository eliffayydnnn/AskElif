# 📸 AskElif Ekran Görüntüleri Rehberi

Bu klasör, AskElif uygulamasının GitHub `README.md` dosyasında sergilenen gerçek ekran görüntülerini içerir.

### 🖼 Beklenen Ekran Görüntüleri Listesi:

1. `chat-page.png` - Public AI Chatbot ekranı (`/chat`)
2. `login-page.png` - Admin Giriş Paneli ekranı (`/`)
3. `dashboard-page.png` - Yönetici İstatistik ve Analiz Paneli (`/dashboard`)
4. `knowledge-page.png` - Bilgi Tabanı Yönetim Ekranı (`/knowledge`)
5. `unknown-questions.png` - Bilinmeyen Soruları İnceleme ve Dönüştürme Ekranı (`/unknownquestions`)
6. `mobile-drawer.png` - Mobil Açılır Menü ve Responsive Ekran Görünümü (<= 768px)

---

### 📌 Ekran Görüntülerini Güncelleme Adımları:
1. Uygulamayı `npm run dev` ve `dotnet run` ile yerel ortamda başlatın.
2. Tarayıcıda ilgili sayfaları açıp ekran görüntülerini alın.
3. Ekran görüntülerini yukarıdaki dosya isimleriyle `docs/screenshots/` klasörüne yerleştirin.
